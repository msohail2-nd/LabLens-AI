# LabLens AI — Research Continuity Prototype

LabLens AI is an early-stage research continuity concept for graduate researchers, academic labs and R&D teams dealing with scattered notebooks, instrument records, spreadsheets and project files. Its intended value is recovering the evidence and context of previous experimental decisions while keeping the researcher in control.

## Intended user and central task

A graduate researcher who returns to an older experiment wants to find relevant notes and CSV revisions, distinguish supported facts from contradictory records, and identify the unresolved question before reporting results to an advisor.

The prototype's proposed flow is: open the sample demo, load fictional experiment records, request a reconstruction, inspect source excerpts and conflicting details, acknowledge/review evidence, and optionally join the beta.

## How to try the prototype

1. Open the live prototype link above and find **Try sample notes / Try the research demo** (check whether the latest version is deployed).
2. Load the fictional NiO-17 experiment. Inspect the attributed notebook notes and dated CSV revision.
3. Search/reconstruct the experiment, then compare the 3:1 and 1:1 solvent-ratio records.
4. Observe that the demo flags the inconsistency rather than selecting an unsupported value; use the review control and note its limits.
5. Optionally try a small, nonconfidential TXT or CSV file in the local demo. Do **not** upload private experimental data.
6. If interested, use the separate beta-interest form.

## Development stack and startup

Replit project stack (reported by code audit): pnpm monorepo; TypeScript; React, Vite, Tailwind CSS; Express 5; Zod; PostgreSQL with Drizzle ORM.

From the Replit workspace, install dependencies with pnpm and run the workspace scripts documented in replit.md.

- Website development: pnpm --filter @workspace/lablens-ai run dev
- API development: pnpm --filter @workspace/api-server run dev
- Website automated tests: pnpm --filter @workspace/lablens-ai run test
- Website typecheck: pnpm --filter @workspace/lablens-ai run typecheck
- API typecheck: pnpm --filter @workspace/api-server run typecheck
- Production build: pnpm run build

The API uses the DATABASE_URL environment variable. Never add credentials or a real database connection string to public GitHub. The website and test suite may depend on source files not yet synchronized from Replit.

## Risk and data handling

This product's principal risks are research-integrity errors (inventing experimental conditions from incomplete records) and accidental disclosure of confidential research information. The sample demo is intended to run deterministically in the browser and display sources and unresolved contradictions. The separate beta-interest form sends contact/research-interest details to the API and stores them in PostgreSQL. The project does **not** demonstrate secure handling or storage of sensitive scientific records.

Use fictional, synthetic or appropriately de-identified information in all screenshots, evaluations and public documentation.
